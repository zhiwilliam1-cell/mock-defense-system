# AI-Assisted Simulated Defense System

An AI-assisted practice platform for academic presentations and defenses, designed with engineering students in mind. It combines presentation materials, speech interaction, simulated examiner questions, and personalized feedback in one practice workflow.

## Planned experience

1. Upload presentation slides for the system to understand the research context.
2. Deliver an oral presentation using speech interaction.
3. Respond to relevant questions and follow-up questions from simulated examiners.
4. Review a personalized report with evidence and suggestions for improvement.

## Planned feedback

The system aims to assess presentation and defense performance across multiple dimensions:

- Speech fluency and presentation delivery.
- Clarity and accuracy of academic language and terminology.
- Logical structure and completeness of the research narrative.
- Relevance and completeness of answers to academic questions.
- Actionable suggestions for improving content and presentation skills.

## Project status

This project is in the planning stage. Features, architecture, and implementation details may change as development progresses.

## Intended audience

Students and educators interested in repeatable, independent practice for academic presentations and defenses, particularly in engineering and STEM education.
